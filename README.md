### 🔥 Projetos em destaque

#### 🔮 [SoftSmart Predict](https://github.com/JoaoGabrielFurtado/SoftSmart)
Sistema inteligente de previsão de ocupação de estacionamentos. Um modelo de **Machine Learning (ML.NET)** integra dados climáticos (OpenWeather) e feriados para aumentar a previsibilidade da ocupação de vagas, apoiando decisões operacionais. Entregue em versões **Desktop (WinForms)** e **Web Mobile-First (Blazor Server)**.

#### 📚 Letrify – Rede Social para Leitores
Projeto acadêmico com um sistema de recomendação (matching) baseado em IA para conectar usuários com gostos literários semelhantes, sobre uma arquitetura desacoplada de Frontend/Backend com perfil, avaliação de livros e feed social. *(C#, .NET, SQL Server, API RESTful)*

#### 💪 Sistema de Gestão de Treinos
Projeto pessoal para organizar treinos de academia por dia/grupo muscular, com feedback em gráfico das progressões. Backend em **C#/SQL Server** e frontend em **JavaScript/HTML5/CSS**.
